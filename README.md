# Customer Behavior Analysis

## 📌 Project Overview

This project analyzes customer purchasing behavior using **MySQL**, **VS Code (Python)**, and **Power BI** to generate business insights from retail sales data. The workflow includes data extraction, SQL-based analysis, data processing, and interactive dashboard creation for decision-making.

## 🛠️ Tools & Technologies

* **MySQL** – Data storage, SQL queries, and business analysis
* **VS Code (Python)** – Data cleaning, preprocessing, and analysis
* **Power BI** – Interactive dashboard development and data visualization

## 🔄 Project Workflow

1. Imported customer transaction data into MySQL.
2. Wrote SQL queries to analyze customer behavior, revenue, discounts, subscriptions, shipping methods, product performance, and customer segmentation.
3. Used Python in VS Code for data preparation and validation.
4. Connected the processed data to Power BI.
5. Designed an interactive dashboard to visualize key business metrics and customer insights.

## 📊 Dashboard Highlights

* Total Revenue Analysis
* Customer Demographics (Age & Gender)
* Category & Product Performance
* Discount Usage Analysis
* Subscription Status Analysis
* Shipping Method Comparison
* Customer Segmentation
* Revenue by Age Group
* Top Products and Purchase Trends

## 📈 Key Business Insights

* Compared revenue generated by male and female customers.
* Identified high-value customers using discounts.
* Ranked products based on customer ratings.
* Analyzed spending across shipping methods.
* Compared subscriber vs. non-subscriber purchasing behavior.
* Calculated discount percentages by product.
* Segmented customers into New, Returning, and Loyal groups.
* Identified the top purchased products within each category.
* Evaluated repeat buyer subscription trends.
* Measured revenue contribution across different age groups.
